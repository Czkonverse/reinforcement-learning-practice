# Dyna-Q 学习笔记：从"用完就扔"到"脑内练习"

## 0. 一句话总结

**Dyna-Q = Q-learning + 一个"日记本"（模型）+ 每走一步，把日记本里的旧经验在脑子里重放 n 遍。**

Q-learning 每步只"用一次"经验；Dyna-Q 把每一条经验记下来反复用，从而学得更快。

---

## 1. 你之前学过的算法，共同点是什么

回顾你已经实现的算法：

- **Q-learning**（off-policy）
- **SARSA / Expected SARSA**（on-policy）
- **n-step SARSA**（n 步自举）

它们有个共同特征：**无模型（model-free）**——不显式地学环境长什么样，只用"真实交互得到的经验"逐条更新 Q 表。

这带来一个问题：**经验用完就扔**。比如跌了一次悬崖（-100），这条经验只更新了 Q 表里的某一格，就再也没用了。下次想再学，只能靠真实环境再跌一次。

> 类比：你只通过"亲自试错"学习，每次摔倒只让你学到这一个动作不对，不会去复盘、更不会举一反三。

---

## 2. 第一个新概念：模型（Model）

**模型 = 对"环境如何运转"的记录。**

对表格型环境，模型可以简单到只是一张表：

```
Model[(s, a)] = (r, s', done)
```

意思是："我曾经在状态 `s` 执行动作 `a`，环境给了我奖励 `r`，并把我带到了 `s'`，且这次是否结束（done）。"

它就像一本**日记本**：每次真实交互后，把 `(s, a)` 发生了什么记一笔。这个"学习模型"的过程叫 **model learning**，代价极低——不需要任何算法，就是抄日记。

---

## 3. 第二个新概念：规划（Planning）

有了日记本，就可以在**不碰真实环境**的情况下"脑补"了。

**规划 = 从模型里读出模拟经验，用它更新 Q 表。**

于是经验有了两个来源：

| | 直接强化学习（direct RL） | 间接强化学习（indirect RL） |
|---|---|---|
| 经验来源 | 真实交互 | 模型生成的模拟经验 |
| 例子 | Q-learning 更新 | 规划（planning） |

> 类比：第一次到过终点之后，你不需要再走一遍真实迷宫，闭上眼睛在心里把那条路"过"几遍，就能加深记忆。

Dyna 正是把这两条路**合二为一**的架构：**同一个 Q 表，既吃真实经验，也吃模拟经验。**

---

## 4. Dyna 架构总览

每走一个真实步骤，agent 做三件事：

```
 1) 真实学习:  Q(S,A) ← Q(S,A) + α[ R + γ·max_a' Q(S',a') − Q(S,A) ]
                    │
 2) 记日记:    Model[(S,A)] ← (R, S', done)
                    │
 3) 脑内规划(重复 n 次):
       随机抽一条"见过"的 (s,a)
       从 Model 读出 (r, s', done)
       Q(s,a) ← Q(s,a) + α[ r + γ·max_a' Q(s',a') − Q(s,a) ]   ← 公式一模一样
```

注意：**第 1 步和第 3 步用的是同一条 Q-learning 更新公式**，区别只是喂进去的是真实经验还是模拟经验。

---

## 5. Dyna-Q 算法（伪代码，对照第 4 节）

```
初始化 Q(s,a) = 0，Model 为空

循环每个真实步骤：
    S ← 当前状态
    A ← ε-greedy(S)                      # 选动作（和其它 agent 一样）
    执行 A，观察到 R, S', done           # env.step(A)

    # ① 真实学习（和 Q-learning 完全一样）
    Q(S,A) ← Q(S,A) + α[ R + γ·max_a' Q(S',a') − Q(S,A) ]   # done 时 target = R

    # ② 记日记
    Model[(S,A)] ← (R, S', done)

    # ③ 脑内规划 n 次
    repeat n 次:
        随机抽一个见过的状态 s
        随机抽一个在 s 里做过的动作 a
        (r, s', done) ← Model[(s,a)]
        Q(s,a) ← Q(s,a) + α[ r + γ·max_a' Q(s',a') − Q(s,a) ]
```

---

## 6. n 是什么？

`n` = 每个真实步骤后做的**规划次数**，是 Dyna 最核心的超参数：

- **n = 0**：退化成**纯 Q-learning**（不脑补）；
- **n 越大**：每个真实步骤的"价值"被放大越多，学得越快，但计算量也越大。

典型取值：迷宫 / 网格类环境常用 n = 5 ~ 50。书里的动态迷宫实验里，n=50 时 agent 几乎能在迷宫一变就立刻适应。

---

## 7. 一个具体例子（结合 CliffWorld）

在悬崖行走里，agent 从左上出发，目标是右下，途中是悬崖（-100）。

假设 agent 第一次探索时**不小心跌进了悬崖**（比如在 `(3,0)` 向右走）：

1. **真实学习**：`Q((3,0), right)` 被 -100 惩罚；
2. **记日记**：`Model[((3,0), right)] = (-100, (3,0), False)`（跌下悬崖后回到起点，未结束）；
3. **脑内规划**：此后每走一步，都会随机重放这条记录 n 次，让 `Q((3,0), right)` 的 -100 反复被确认。

于是**下次走到 `(3,0)` 附近时，Q 表已经很明确地"知道"右边是悬崖**，不需要再真实地跌一次。这就是 Dyna 比 Q-learning 快的地方——**好的和坏的经验都被放大传播**。

---

## 8. Dyna-Q 与 Q-learning 对比

| | Q-learning | Dyna-Q |
|---|---|---|
| 每步真实更新 | 1 次 | 1 次 |
| 每步模拟更新 | 0 次 | n 次 |
| 是否记模型 | 否 | 是 |
| 经验利用方式 | 用完即弃 | 反复重放 |
| 样本利用率 | 低 | 高 |
| 代码复杂度 | 简单 | 稍多一张表 |

## 9. 局限与后续扩展

- **模型会错**：环境是随机时，"抄一次日记"得到的模型可能失真；用错的模型做规划会把错误放大。→ 解决：`Dyna-Q+`（给长时间没重放的状态加探索奖励），或模型存多次观察再做采样。
- **重放没有重点**：均匀随机重放效率低。→ 解决：`prioritized sweeping`（优先重放 Q 值变化大的状态）。
- **模型本身要学**：更复杂的做法是用函数 / 神经网络来学模型（Model-Based RL、MuZero 等）。
